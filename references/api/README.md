## Rules for assistants

- Read the English file by default. Read the `-zh.md` file when the user writes in Chinese or asks for the Chinese documentation.
- Each file is one document; use its table of contents / headings to find the section you need.
- Never invent endpoints, parameters, response fields, limits or error codes. Never paste API keys or secrets.
